Gallery media organization

Use these folders for gallery assets:

- science/: microscopy, condensates, cellular organization, and other research visuals.
- lens/: travel, mobile photography, and quiet observations outside the lab.

Current page references:

- gallery-science.html uses files in gallery/science/.
- gallery-lens.html uses the photographs currently placed in gallery/lens/.

When adding personal photographs, place them in gallery/lens/ and update the corresponding image paths in gallery-lens.html.
